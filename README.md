# Portfolio Website (CSC 337 Assignment 1)

A four page portfolio built with plain HTML and CSS only (no JavaScript, no template).

Pages: index.html, hobbies.html, media.html, contact.html
Styles: css/style.css
Images: images/

Techniques: semantic HTML5, Flexbox navigation, CSS Grid layouts, sticky header, styled tables with hover, styled form, responsive media query.
